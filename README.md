# ChessReview ♟️

A full-stack chess analysis application designed to simulate the "Game Review" feature found on popular chess platforms. The system analyzes chess moves, evaluates board states, and suggests optimal alternatives.

## 🚀 Purpose of the Project
As a first-year Computer Engineering student, my primary goal with this project was not to build a commercial product, but to understand the core concepts of system architecture. I built this to learn:
- How the Frontend and Backend communicate via APIs.
- How to manage complex algorithms and data flow.
- How to integrate AI/Logic-based tools into a software ecosystem.

## 🛠️ Technologies Used
- **Frontend:** [Burada istifadə etdiyin dili/freymvorku yaz: məs. HTML, CSS, JavaScript]
- **Backend / AI Logic:** Python
- **Version Control:** Git & GitHub

## ⚠️ Important Note on Development
This project was developed with the active assistance of AI tools (like ChatGPT/Claude) for generating and structuring the code base. My focus was on **System Architecture and Integration** rather than writing every single line of code from scratch. I managed the components, analyzed the data flow between the backend and frontend, and debugged the architectural errors. 

## 📌 Current Status
The project is currently in the **development and testing phase**. The application is functional, but the accuracy of the AI-based move analysis is still being optimized.

## 🎯 Future Goals
My next step is to completely rebuild the backend of this system using **Java (Spring Boot)** to achieve industry-standard architecture, improve performance, and reduce reliance on AI-generated logic.
